# data-qd-224 · 构建缓存对象存储

构建者按标签发布制品字节，存储以 SHA-256 地址复用相同内容；读取者按标签获取并校验制品完整性。发布原子更新引用，回收只删除当时未被任何标签引用的对象。单个本地 SQLite 文件存放小型制品，当前未提供跨缓存复制或临时保留租约。

Python 3.9+，仅标准库。示例使用本仓合成制品和临时数据库。

```sh
python3 -B -m unittest -v
python3 -B demo.py
```

两个标签指向同一制品时显示 `same digest: True`；旧标签移除后输出 `reclaimed: 1`，稳定标签仍取回 `b'artifact-v2'`。
